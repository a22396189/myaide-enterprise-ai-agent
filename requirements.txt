# 全部釘死成在這台機器上實際驗證過能一起裝好、也真的跑得動的版本組合
# （不是隨便挑的，是 `pip freeze` 出來的），而不是用開放式的 >=。
#
# 原因：這個專案同時疊了 langchain 系列、google-generativeai、
# sentence-transformers（帶 torch/transformers 整條 ML 依賴鏈）——
# 開放式版本範圍會讓 pip 的相依性解析器在一個全新環境裡要嘗試非常多種
# 版本組合，輕則跑很久、重則直接丟 "resolution-too-deep" 放棄，或是
# backtracking 到很舊的 langchain-google-genai（1.0.1–1.0.6）版本，
# 那些版本又要求 google-generativeai<0.6.0，跟我們自己需要的新版
# google-generativeai 互斥，最後變成 "ResolutionImpossible"。
# 全部釘死版本後，pip 完全不用做版本搜尋，安裝速度也快很多。
#
# 升級任何一個套件前，建議先在乾淨的虛擬環境裡用
# `pip install --dry-run -r requirements.txt` 確認新組合真的解得開。
