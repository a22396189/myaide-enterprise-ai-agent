# 全部釘死成在這台機器上實際驗證過能一起裝好、也真的跑得動的版本組合，
# 而不是用開放式的 >=：這個專案同時疊了 langchain 系列、google-genai、
# sentence-transformers（帶 torch/transformers 整條 ML 依賴鏈），開放式
# 範圍會讓 pip 的解析器 backtracking 很久甚至失敗。
#
# 2026-10 遷移到 langchain 1.x：gemini-2.5-flash 已不開放給新使用者，
# Gemini 3.x 的 function calling 需要把 thought signature 帶回下一輪請求，
# 舊的 langchain-google-genai 1.0.10 不支援（會回 400 missing thought_signature）。
# 升級後 langgraph 與 langchain-core 版本宣告一致，不再需要
# `pip install --no-deps` 分兩階段安裝。

# `pip install --dry-run -r requirements.txt` 確認新組合真的解得開，
# 並重跑 `pytest tests/ -v` 與 `python -m evals.run_evals --live`。
